HIGHLIGHTS

为旗舰 5G CPE 打造的卓越性能

告别发热断流与性能短板，软硬件协同全面释放联发科 Filogic 潜力。

5G 蜂窝全网通

深度适配鼎桥 MT5700M 模组，原生支持 5G SA/NSA 双模全网通。Rust/Tokio 常驻后端独占 AT 串口，12 个可视化页面覆盖信号、拨号、扫频锁频与短信。

智能风扇温控

硬件级双传感器实时轮询（SoC 核心 + 5G 基带模组），PWM 阶梯无级自动调速，支持自定义起转温度阈值，静音与长效散热平衡兼得。

双链路无缝倒换

一键切换「仅 5G 蜂窝」「仅千兆 WAN」「5G 优先」与「有线优先」四种模式，通过接口 metric 与默认路由优先级实现主备倒换（无需 mwan3）。

硬件加密加速

内核集成 kmod-cryptodev 与 kmod-tls，为 HomeProxy 等代理分流工具提供加密卸载能力，千兆满速转发时显著降低 CPU 占用。

MT5700M 5G 模组管理

LuCI 前端 + Rust/Tokio 常驻后端单包融合

  • 实时状态大屏：SA/NSA、频段、RSRP/RSRQ/SINR、载波聚合，速率取自内核网卡计数
  • 拨号与接口自动化：APN/PDP 配置与自动拨号，自动复用或创建 MT5700M 接口
  • 全网扫频 · 定时锁频 · AT 终端：频段/小区扫描、定时锁频与 Web AT 指令调试
  • 短信中枢 & 温度联动：UTF-16 长短信去重；RPC 取芯片温度写入 /var/run/mt5700m/temperature
luci-app-h5000m-fancontrol 硬件级 PWM

智能风扇闭环温控

解决 5G 高负载大带宽发热，7x24 小时满速不降频

  • 双传感器轮询：并发采集 Filogic SoC 核心与 MT5700M 5G 模组两路温度
  • 自适应阶梯变速：基于双路最高温自适应调节转速，低温静音、高温速冷
  • 温控策略全自定义：自主设置起转阈值、警报阈值与转速步长
  • 寿命保护算法：防频繁起停抖动，延长物理风扇轴承寿命
luci-app-h5000m-netmode metric 主备倒换

网络模式无缝切换

5G 蜂窝移动网络与千兆 WAN 口光纤双网融合

  • 四种模式一键切换：wan_first / modem_first / wan_only / modem_only
  • 路由优先级倒换：调整 wan / MT5700M metric，network reload 即刻生效
  • 主备自动接续：主链路默认路由消失时内核自动切换备用链路，无需 mwan3
  • IPv6 联动：同步调整有线与蜂窝两路的 IPv6 获取，避免 v4/v6 路由分裂

FLASHING GUIDE

刷机与 5G CPE 初次配置指南

清晰直观的步骤指引，助您轻松完成固件更新与 5G 高速连网。

获取并校验固件

01

1. 选择对应模组（MT5700 / MT5700M）的 H5000M-<模组>-<YYYYMMDD>-sysupgrade.bin。
2. 推荐启用 ACG2 极速代理，国内千兆满速直下。
3. 对照 Release 正文里的 SHA256 校验文件完整性。

上传与刷写系统

02

1. 打开原有后台 192.168.10.1。
2. 进入菜单：系统 ➔ 备份/升级 ➔ 刷写新的固件。
3. 上传 bin 文件确认校验和后点击「继续」，等待 2-3 分钟重启（切勿断电）。

开箱体验 5G 极速

03

1. 默认 Wi-Fi 为 OWRT（密码 12345678）。
2. 访问 192.168.10.1，账号 root 无密码直接回车。
3. 进入「网络 ➔ 移动网络 ➔ 5G 模组管理」查看信号强度、锁频或收发短信。
