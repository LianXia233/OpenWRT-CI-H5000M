# MT5700M 模组管理 —— 旧插件（FAN789/luci-app-mt5700m，上游 v3.0.7）
# LuCI 前端 + 原生 C 传输程序 mt5700m-transport，入口「网络 → 移动网络 → MT5700M 模组」。
#
# 每次构建固定产出两套固件，本文件对应 MT5700M 那一套（另一个作业用 Config/MT5700.txt）。
# 两套插件互斥：都独占 MT5700M 的 AT 串口，同一份 .config 不允许同时启用。
# CI 在各自作业里追加对应文件，并在 make defconfig 之后校验「本套为 y、另一套为 n」，
# 不符（同时为 y / 同时为 n）都会直接失败。
# 风扇控制随本套固件沿用 FAN789 原版（v2.1.1 shell 控制器；Packages.sh 按
# WRT_MODEM 条件克隆，GENERAL.txt 的启用项两套通用）。
CONFIG_PACKAGE_luci-app-mt5700m=y
# 语言包依赖主包，必须同批安装
CONFIG_PACKAGE_luci-i18n-mt5700m-zh-cn=y
# 旧插件运行时依赖：flock 用于串行化 AT 操作
# （新插件由 Rust 后端内部互斥，不需要该包，故只在旧插件配置里启用）
CONFIG_PACKAGE_flock=y
