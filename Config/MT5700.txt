# MT5700M 模组管理 —— 新插件（LianXia233/luci-app-mt5700）
# 单包融合 LuCI 前端与 Rust/Tokio 后端，入口「网络 → 移动网络 → 5G 模组管理」。
#
# 每次构建固定产出两套固件，本文件对应 MT5700 那一套（另一个作业用 Config/MT5700M.txt）。
# 两套插件互斥：都独占 MT5700M 的 AT 串口，同一份 .config 不允许同时启用。
# CI 在各自作业里追加对应文件，并在 make defconfig 之后校验「本套为 y、另一套为 n」，
# 不符（同时为 y / 同时为 n）都会直接失败。
CONFIG_PACKAGE_luci-app-mt5700=y
# 语言包依赖主包，必须同批安装（否则 opkg/apk 会报 no such package）
CONFIG_PACKAGE_luci-i18n-mt5700-zh-cn=y
